# Local development and future sync runbook

| Symptom                          | Diagnostics                                                                                                        | Recovery                                                                                                                       |
| -------------------------------- | ------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------ |
| npm ci fails                     | Check Node/npm versions, registry reachability, package-lock consistency and permission error; do not paste tokens | Use compatible Node 24 line; request approval for host changes; rerun approved network operation rather than bypassing sandbox |
| Vite rejects flag                | Read CLI error; Vite accepts --host, not --hostname                                                                | `npm run dev -- --host 127.0.0.1 --port 4101 --strictPort`                                                                     |
| Port 4101 busy                   | Identify own running dev session/process; do not kill unknown processes                                            | Reuse known server or select another local port and update browser test baseURL deliberately                                   |
| Demo fails to load               | Generic UI error; run boundary tests and inspect synthetic fixture schema                                          | Fix malformed data, retry; do not log a future provider's raw private payload                                                  |
| No inbox results                 | Check query, category and priority combined with AND                                                               | Clear filters; fixture is not missing mail                                                                                     |
| Types/lint fail                  | Read first actionable diagnostic; check Vite env types and hooks rules                                             | Make narrow fix, rerun affected checks; avoid disabling rules wholesale                                                        |
| Coverage below threshold         | Inspect coverage report and contract paths                                                                         | Add meaningful boundary/failure tests; do not lower thresholds to hide failures                                                |
| Playwright missing browser       | Compare installed Playwright with cached browser revisions                                                         | Request approval for local browser download or host library installation if required; do not use sudo automatically            |
| Dependency audit flags minimatch | Run npm audit; inspect paths and compatible upstream releases                                                      | Document moderate development risk; no force downgrade/major override without compatibility checks                             |
| Future 401/expired token         | Confirm local expiry/granted scopes without printing token                                                         | Pause sync, preserve checkpoint, explicit user reconnect                                                                       |
| Future 403/429                   | Distinguish quota/rate reasons from scope/disabled API                                                             | Bounded backoff for retryable limits; stop and explain non-retryable authorization failure                                     |
| Future history.list 404          | Identify endpoint and checkpoint age                                                                               | Full reconciled rescan; preserve visible cache as stale during recovery                                                        |
| Future invalid page token        | Inspect sanitized job/coverage state                                                                               | Restart safe enumeration with unique upserts, never skip a page                                                                |
| Future cache missing/quota error | Check IndexedDB availability, storage pressure and schema                                                          | Explain reimport/delete options; never ask for mail/password in a bug report                                                   |

No Gmail failure scenario above is currently executable; those rows are design procedures. Before personal production validate these recoveries with mocks and owner-approved account tests. Incidents involving credentials require revocation and private reporting, not merely clearing the UI.
