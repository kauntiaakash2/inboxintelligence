# Security policy

The current release defaults to synthetic data and optionally reads a bounded Gmail metadata sample after explicit authorization. Automated verification uses fake Google services only. See [security design](docs/security/SECURITY.md), [threat model](docs/security/THREAT_MODEL.md), and [privacy policy](docs/security/PRIVACY.md).

Do not post credentials, tokens, private email content or exploit details publicly. A private reporting address has not been established. Contact the repository owner through an existing verified private channel to arrange disclosure. If none exists, request a private reporting method without disclosing the vulnerability publicly. No response-time guarantee or supported-version SLA is established yet.
